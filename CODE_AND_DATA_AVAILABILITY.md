# Code and data availability

## Manuscript-ready English

### Code availability

The CarbTune source code, input validation utilities, processed model inputs and reproducible software environment are available at https://github.com/NJU-Water-Quality/CarbTune. The repository includes scripts for feature construction, two-stage XGBoost training, cross-validation and prediction.

### Data availability

The processed growth-curve data, carbon-source structures and protein FASTA files used to train CarbTune are provided with the code repository at https://github.com/NJU-Water-Quality/CarbTune. The metagenomic sequencing data generated in this study are available in the NCBI Sequence Read Archive under BioProject accession PRJNA1432220. Source database identifiers and any additional repository accession numbers are reported in the manuscript and Supplementary Information.
